# ProxPaste

Готовые версии для Windows и macOS (x64 и ARM64): [скачать сборки](Release/README.md).

Графическое приложение на Go: ввод текста из буфера обмена в Proxmox noVNC через нажатия клавиш. Пользователю не нужны Go, Python или агент в гостевой ОС.

## Использование

1. Включите English (US) на хосте и в гостевой ОС. Выключите Caps Lock.
2. Нажмите «Из буфера обмена» и проверьте текст. Предпросмотр можно редактировать.
3. Выберите задержку 0–60 секунд и интервал 0–1000 мс. Для медленной консоли попробуйте 100–200 мс. При задержке 0 ввод начинается сразу после отпускания модификаторов; удобно запускать его горячей клавишей из noVNC. Интервал 0 убирает дополнительную паузу между символами; короткое удержание каждой физической клавиши сохраняется.
4. Для многострочного текста разрешите Enter и Tab. Enter может сразу выполнить команду, включая завершающий перенос строки.
5. Нажмите «Начать ввод», затем щёлкните внутри noVNC до окончания отсчёта. Отпустите Ctrl, Alt/Option, Shift и Win/Command.
6. Не переключайте окна и не печатайте. Esc останавливает отправку. Уже отправленные нажатия не отменяются; сам Esc также может попасть в консоль. Закрытие окна скрывает его в трей и не прерывает ввод. Пункт «Выход» в меню значка сначала останавливает ввод, затем завершает приложение.

## Трей и горячая клавиша

- **По умолчанию: Windows — Ctrl+Alt+V, macOS — Control+Option+V.** Горячая клавиша работает глобально, в том числе со скрытым окном ProxPaste. Она читает текущий буфер, использует выбранную задержку, интервал и разрешение Enter/Tab, не открывает окно и не переключает фокус. Предпросмотр при этом заменяется текущим текстом буфера.
- Установите фокус внутри noVNC, нажмите сочетание и отпустите клавиши. Перед началом ввода приложение дополнительно ждёт отпускания модификаторов (до 10 секунд). Повторные вызовы во время ввода игнорируются.
- Значок трея Windows / строки меню macOS позволяет открыть окно, остановить ввод и выйти. В Windows щелчок по значку открывает окно, правая кнопка открывает меню; сворачивание также скрывает окно в трей. В macOS закрытие окна оставляет значок в строке меню.
- Состояние отображается в подсказке значка; на macOS также в меню. Если горячая клавиша занята, приложение сообщает об этом в окне. При отказе вставки из трея Windows показывает уведомление, macOS — звуковой сигнал и причину в меню значка.
- Запуск сразу в трее: `ProxPaste.exe --tray` в Windows или `open ProxPaste.app --args --tray` на macOS. Автозапуск в системе не устанавливается.

### Сохранение всех настроек

Кнопка **«Сохранить всё»** сохраняет горячую клавишу, задержку перед стартом, интервал между символами и разрешение Enter/Tab. После перезапуска все четыре параметра восстанавливаются. Содержимое буфера и текст редактора на диск не записываются. Сохранение выполняется по нажатию кнопки; несохранённые изменения параметров действуют только в текущем сеансе.

Недопустимые значения не записываются. Если горячая клавиша занята или файл не удалось записать, предыдущие сохранённые настройки остаются в силе. Старые файлы с одной горячей клавишей поддерживаются: недостающие параметры получают значения 5 секунд, 40 мс и выключенное разрешение Enter/Tab.

### Настройка сочетания

В блоке «Горячая клавиша» введите сочетание и нажмите **«Сохранить всё»**. Например: `Ctrl+Shift+V`, `Alt+F8`, `Command+Shift+J` (macOS). Поддерживаются модификаторы Ctrl/Control, Alt/Option, Shift, Win/Command и клавиши A–Z, 0–9, F1–F12. Нужен хотя бы один из Ctrl, Alt/Option или Win/Command. Esc оставлен для остановки. Названия клавиш вводятся латиницей.

Изменение применяется сразу и восстанавливается при следующем запуске. Если комбинация занята/зарезервирована ОС или настройки не удалось записать, прежняя регистрация сохраняется. Кнопка **«По умолчанию»** восстанавливает исходное сочетание. Во время отправки текста настройки заблокированы.

Файл со всеми настройками (без содержимого буфера):

- Windows: `%AppData%\ProxPaste\settings.json`.
- macOS: `~/Library/Application Support/ProxPaste/settings.json`.

## HiDPI

В Windows включён Per-Monitor DPI Awareness V2: размеры элементов и шрифта пересчитываются при переносе окна между мониторами с разным масштабом. В macOS интерфейс Cocoa работает в логических координатах, включена поддержка Retina. Тёмный интерфейс использует графитовые блоки настроек, контрастный текст и бирюзовые основные кнопки. Заголовок Windows окрашивается через DWM на поддерживаемых версиях ОС; macOS использует Dark Aqua.

Собственная иконка «буфер со стрелкой» встроена в окно, трей, Windows exe и macOS app. Для macOS подготовлена монохромная версия строки меню, адаптирующаяся к системному оформлению.

Поддерживаются все печатные ASCII-символы, Enter и Tab. Кириллица и emoji отклоняются до старта. Ctrl+V и Unicode-вставка ОС не используются. Ввод идёт в активное окно, приложение не проверяет фокус noVNC. Счётчик показывает отправку, а не подтверждение гостем. Сначала проверьте работу в редакторе гостя.

В Windows ввод в окно с более высокими правами может блокироваться системой. На macOS разрешите ProxPaste Accessibility и Input Monitoring в System Settings → Privacy & Security, затем перезапустите приложение. Используйте .app по постоянному пути: при go run разрешения могут относиться к Terminal и временному бинарнику.

Текст хранится в памяти, не записывается в логи и не отправляется приложением по сети. Системный буфер не изменяется.

## Сборка Windows

Нужен Go 1.23+. Сторонних Go-зависимостей и C-компилятора не требуется:

```powershell
go test ./...
go build -trimpath -ldflags '-H=windowsgui -s -w' -o dist/ProxPaste.exe .
```

Распространяйте один файл dist/ProxPaste.exe. Дополнительные DLL не нужны. Windows использует Win32 и SendInput. Реализованы amd64 и arm64; локальная сборка — amd64.

Иконки и ресурсы `resource_windows_*.syso` уже входят в проект. Чтобы изменить графику, отредактируйте геометрический рисунок в `cmd/assets/main.go` и запустите `go generate .`. Генератор использует только стандартную библиотеку Go, создаёт PNG, ICO, ICNS и ресурсы PE для amd64/arm64. Для сборки не нужны сторонние утилиты работы с ресурсами.

## Сборка macOS

На Mac нужны Go 1.23+ и Xcode Command Line Tools (xcode-select --install):

```sh
go test ./...
sh scripts/build-macos.sh
```

Результат: dist/ProxPaste.app и ZIP для архитектуры Go (Apple Silicon или Intel). Пользователю инструменты разработчика не нужны. Логика написана на Go; небольшой мост Objective-C через cgo предоставляет Cocoa и Core Graphics. Используются только системные библиотеки.

Для сборки нужен SDK macOS, поэтому простого GOOS=darwin go build на Windows недостаточно. Скрипт делает ad-hoc подпись. Для публичного распространения без предупреждений Gatekeeper нужны Developer ID и notarization с вашей учётной записью Apple. Подпись Windows также не включена.

## Автоматические сборки

.github/workflows/build.yml собирает Windows x64 и macOS Apple Silicon/Intel по ручному запуску или тегу v*. Результаты сохраняются в артефактах GitHub Actions. Workflow нужно запустить в вашем репозитории: создание файла локально облачную сборку не запускает.

## Проверки

`go test ./...` проверяет все печатные ASCII-символы, нормализацию переносов, ожидание отпускания модификаторов, разбор сочетаний, сохранение/загрузку настроек и откат при ошибке записи. На Windows дополнительно проверяются размеры структур Win32, масштабы DPI, подсказки трея и встроенный значок (при наличии собранного exe).

Нативная интеграционная проверка Windows создаёт скрытое настоящее окно и временный значок трея, проверяет закрытие в трей, смену/конфликт/сброс горячей клавиши, сохранение в отдельном временном каталоге, смену DPI 200% → 150% → 100%, геометрию и шрифты, затем завершает приложение. Она не читает буфер и не отправляет клавиши:

```powershell
$env:PROXPASTE_NATIVE_TEST='1'
go test -run TestNativeDesktopLifecycle -v -timeout 20s .
Remove-Item Env:PROXPASTE_NATIVE_TEST
```

Отдельно проверьте на обеих ОС ввод в редактор внутри noVNC через горячую клавишу, Enter/Tab, остановку по Esc и выход через трей во время ввода. macOS-версия требует сборки и проверки на Mac. Проверка нескольких физических мониторов с разным DPI также остаётся ручной.
