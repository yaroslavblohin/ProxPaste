# Готовые сборки ProxPaste

| Система | Архитектура | Файл |
| --- | --- | --- |
| Windows | Intel / AMD x64 | [ProxPaste-Windows-amd64.exe](ProxPaste-Windows-amd64.exe) |
| Windows | ARM64 | [ProxPaste-Windows-arm64.exe](ProxPaste-Windows-arm64.exe) |
| macOS | Intel | [ProxPaste-macOS-amd64.zip](ProxPaste-macOS-amd64.zip) |
| macOS | Apple Silicon (M1 и новее) | [ProxPaste-macOS-arm64.zip](ProxPaste-macOS-arm64.zip) |

Windows: скачайте и запустите подходящий EXE.

macOS: распакуйте ZIP и перенесите ProxPaste.app в «Программы». Разрешите приложению «Универсальный доступ» и «Мониторинг ввода» в настройках конфиденциальности macOS, затем перезапустите его. Приложение имеет локальную ad-hoc подпись, без Developer ID и нотариализации Apple. Windows-сборки не подписаны.

Поддерживаются Windows и macOS; версии для Linux в проекте нет. Go и инструменты разработчика для запуска не нужны.

Контрольные суммы файлов находятся в [SHA256SUMS.txt](SHA256SUMS.txt).

Инструкция по использованию и самостоятельной сборке: [README проекта](../README.md).
